# Fotos livres candidatas (Wikimedia Commons)

Levantamento de 19/11/2026 para as bandas que ainda estão **sem foto própria** em produção. **Nada foi baixado.** Licença livre (Creative Commons ou domínio público), com crédito obrigatório (veja `docs/creditos-imagens.md`). A foto sugerida é a de melhor resolução cuja descrição no Commons cita a banda; a conferência visual ainda precisa ser feita antes de usar.

**68 bandas com sugestão**, 46 sem foto livre.
